## ภาษาไทย

- zter เป็น terminal ที่สร้างด้วย GTK4 และ VTE โดยใช้ธีมเริ่มต้น One Half Dark
- รองรับ wallpaper ภาพที่มากับโปรแกรมและภาพที่กำหนดเอง ปรับ opacity และ reload ได้โดยไม่ต้องปิด เปิดใหม่
- รองรับหลายแท็บ และ เพิ่ม ปิด และลากสลับตำแหน่ง เมื่อเปิดแท็บใหม่จะใช้ path ตามแท็บก่อนหน้า
- เปลี่ยนชื่อแท็บได้ และยังรองรับสถานะการทำงาน เช่น (สถานะของ codex cli กำลังทำงานอยู่)
- ปรับขนาดตัวอักษรแยกแต่ละแท็บด้วย `Ctrl+mouse wheel`, `Ctrl+=` และ `Ctrl+-`
- รองรับ scrollback และ scrollbar
- คัดลอกข้อความ `Ctrl+C`, `Ctrl+V` และ Copy/Paste จากเมนูคลิกขวาได้
- เปิด link ด้วย `Ctrl+left-click`
- ป้องกันปิด terminal โดยไม่ตั้งใจ `Ctrl+C`, `Ctrl+D` มีการยืนยันก่อน
- ตั้งค่าเพิ่มเติมจากไฟล์ json
- รองรับเปิด instance แยก (zter -s)
- มีสอง mode (development) (build release)
- มี icon แยกทั้งสองโหมด
- รองรับ resize window

## English

- zter is a terminal built with GTK4 and VTE, using One Half Dark as its default theme.
- It supports the bundled wallpaper and custom images. Wallpaper opacity can be
  adjusted, and wallpaper changes can be reloaded without closing and reopening
  the application.
- Multiple tabs can be added, closed, and reordered by dragging. A new tab uses the path from the previous tab.
- Tabs can be renamed while still displaying activity status, such as the running status of Codex CLI.
- Font size can be adjusted independently per tab with `Ctrl+mouse wheel`, `Ctrl+=`, and `Ctrl+-`.
- It supports scrollback and a scrollbar.
- Text can be copied with `Ctrl+C` and pasted with `Ctrl+V`. Copy/Paste actions are also available from the secondary-click menu.
- Links can be opened with `Ctrl+left-click`.
- Accidental terminal closure is guarded by confirmation for `Ctrl+C` and `Ctrl+D`.
- Additional options can be configured in a JSON file.
- A separate instance can be opened with `zter -s`.
- It has two modes: development and release build.
- Each mode has a separate icon.
- It supports window resizing.
