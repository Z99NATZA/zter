## ภาษาไทย

- ป้องกัน Ctrl+Z เผลอปิด terminal ที่มี foreground process รันอยู่
- ลาก tab ออกจาก window ปัจจุบัน เพื่อสร้าง window ใหม่ และสามารถลาก tab เพื่อย้าย tab ไปยัง window อื่น
- settings ได้จาก ui
- ปรับความโปร่งได้
- right-click to close tab
- รองรับ Super+H, Super+L เพื่อสลับแท็บซ้าย/ขวา (ต้องตั้งค่าเครื่องเพิ่ม)
- zter hf, zter hm (header bar แบบเต็มและแบบเล็ก)

## English

- `Ctrl+Z` asks for confirmation before suspending an active foreground process.
- Drag a tab out of its window to create a new window, or drop it into another zter window to move it there.
- Edit settings in the application window.
- Adjust the terminal background's transparency.
- Secondary-click a tab to close tabs to its left or right.
- Use `Super+H` and `Super+L` to switch to the previous or next tab, subject to system shortcut settings.
- Use `zter hf` and `zter hm` for the full and mini header modes in release builds.
