## Requirements

Install the Rust toolchain, a C build toolchain, GTK 4.10 or newer, and the GTK4
VTE development files. On Ubuntu:

```bash
sudo apt install build-essential pkg-config libgtk-4-dev libvte-2.91-gtk4-dev
```

## Run

```bash
cargo run
```
